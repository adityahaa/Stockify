# Exchange-rate limitations

Currency conversion depends on external HTTP services and fallback behavior. A successful conversion is not proof that a rate is current or accurate. Record the actual source, timestamp, response, and fallback status when evaluating a session. No fixed exchange rate or conversion-accuracy result is asserted by this documentation.

See the [current README](../README.md) and [technical report](../docs/TECHNICAL_REPORT.md). Earlier numerical speedup, confidence, and exchange-rate claims were not backed by committed reproducible benchmarks and have been removed.
